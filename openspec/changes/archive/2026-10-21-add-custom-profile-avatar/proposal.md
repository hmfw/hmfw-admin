# Proposal

## Why

当前个人中心只能根据昵称或账号生成字符头像，用户无法用自己的图片表达身份。需要提供面向普通登录用户的头像维护能力，并保证个人中心与顶部导航始终展示一致、可恢复的头像状态。

## What Changes

- 在个人中心身份摘要区提供头像图片选择、方形裁剪、上传、替换和移除操作。
- 新增当前登录用户专用的头像上传与移除接口，不要求文件管理权限；服务端仅接受受支持的图片内容，并限制文件体积与处理后的尺寸。
- 为用户资料持久化头像地址，并在个人资料与当前用户信息接口中返回该字段。
- 自定义头像上传或移除成功后同步刷新个人中心和顶部导航；没有自定义头像时继续使用现有字符头像作为回退。
- 将头像文件与通用文件管理权限解耦，并在替换、移除头像时清理不再引用的旧头像文件。
- 增加前后端自动化测试，覆盖图片校验、上传替换、移除、回退显示、失败保留和跨区域同步。

## Capabilities

### New Capabilities

- `profile-avatar`: 定义登录用户上传、替换、移除和展示个人头像，以及无自定义头像时的生成头像回退行为。

### Modified Capabilities

无。

## Impact

- 后端用户表与 `SysUser` 实体新增头像字段，认证模块的 profile/me DTO 与服务逻辑随之扩展。
- 认证模块新增头像专用 multipart 上传和移除接口，并复用或提取现有本地磁盘存储基础能力。
- 前端影响 `Profile.vue`、`BasicLayout.vue`、认证 API、用户资料类型、共享头像展示逻辑和相关测试。
- 需要引入或采用图片裁剪方案；服务端图片校验不能仅信任扩展名或客户端 MIME 类型。
- 现有用户与 API 调用保持兼容，空头像字段继续触发现有生成头像逻辑，无破坏性变更。
